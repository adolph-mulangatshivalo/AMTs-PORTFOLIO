## 9. UI/UX Design Decisions
Every element on this website was a conscious design decision aimed at maximizing user engagement. I decided to make the cursor interactions feel rewarding. For example, when you hover over my primary buttons, they do a subtle shake and cast a hard shadow. This gives immediate, satisfying feedback to the user.

I also utilized an Intersection Observer in JavaScript to create reveal animations. As the user scrolls down, the elements fade in and slide up from the bottom. This prevents the user from feeling overwhelmed by a massive wall of text immediately upon loading the page. It makes the browsing experience feel like unwrapping a gift step by step. I even added a special animation for the Contact header to surprise the user at the very end of their scrolling journey. The user interface had to feel as smart as the backend code I usually write.

## 11. Tech Stack
I kept the tech stack incredibly pure and fundamental. I deliberately did not use React, Vue, Tailwind CSS, or any heavy libraries. 
* HTML5: For the semantic structure and accessibility of the document.
* CSS3: For all the styling, grid layouts, flexbox alignments, and complex keyframe animations.
* Vanilla JavaScript: For the Document Object Model manipulation, scroll tracking, intersection observers, and the custom two-dimensional physics engine running the zero-gravity room. 

By sticking to the core languages of the web, I ensured the website loads instantly, performs beautifully on low-end mobile devices, and perfectly demonstrates my raw, unfiltered coding ability. It shows I understand how the web works under the hood.

## 12. HTML Structure
My HTML document is meticulously organized. I start with the standard document type declaration and meta tags for viewport scaling to ensure mobile responsiveness right out of the gate. 

Inside the body tag, the navigation element contains my logo and an unordered list of anchor links. The header block holds my hero content. I used span tags with specific classes to style the small bracketed text that looks like code syntax. 

In the about section, I utilized standard div containers organized into a grid system. I used unordered lists for my skills to keep the markup semantic. The projects are housed in their own section where each project is an individual card. I used inline Scalable Vector Graphics for the little arrows inside the project titles to save HTTP requests and keep the site fast. The entire structure is completely semantic, making it friendly for screen readers and search engine optimization.

## 13. CSS Structure
The style sheet is the heart of the website's visual appeal. I started with a global reset to ensure consistency across all browsers, stripping away default margins and padding. 

I set up CSS variables at the very top for all my colors, spacing increments, and fonts. This made it incredibly easy to maintain consistency; if I wanted to change a color, I only had to change it in one place. I heavily utilized CSS Flexbox for aligning items in the navigation bar and the hero section. I used CSS Grid for the project cards and the about section layouts, allowing them to adapt seamlessly to different screen sizes without writing messy media queries for every single element.

The CSS file is also packed with custom animations. I wrote the continuous float for the project cards, the subtle shake for hovering over buttons, and a massive infinite animation that makes my academic average visually pulse on the screen.

## 14. JavaScript Functionality
The script section at the bottom of my HTML file contains four distinct logic blocks that bring the site to life. 
First, I wrote a scroll listener that calculates the scroll percentage to shift the background position of the gradient text on my name. It also tracks the top offset of sections to highlight the active link in the navigation bar dynamically.

Second, I implemented an Intersection Observer. This monitors when elements enter the viewport and adds a visible class to them, triggering the CSS fade-in animations. I optimized it by telling the observer to stop watching elements after they reveal, which saves CPU cycles and keeps the browser running smoothly.

Third, I created a pulsing interval that randomly selects a skill from my skills list and applies a shake class every few seconds, just to catch the user's eye if they are idling on the page.

Finally, the biggest piece of logic is the zero-gravity room. I created an array of objects representing floating icons. I wrote a loop that updates the coordinates of each icon based on velocity variables.

## 15. Responsiveness & Mobile Design
I made sure this website looks perfect on every single device. I used media queries targeting maximum widths to adjust the layout for tablets and smartphones. 

On smaller screens, the hero section switches from a horizontal row to a vertical column layout, placing my text above my image so it does not look cramped. On mobile devices, the navigation bar loses its horizontal layout and becomes a tightly packed row of links. The grids in the About and Projects sections collapse into single columns so the user can just scroll straight down with their thumb without having to squint or zoom in. I also had to add a special padding rule to the top of the HTML element so that clicking a navigation link on mobile does not hide the section title behind the sticky header.

## 18. Deployment Instructions
Deploying this website was an essential part of the process, and I wanted to keep it as elegant as the code itself. Because it is a static site containing only HTML, CSS, JavaScript, and image assets, I do not need a complex backend server or a massive database. 

I host this portfolio using GitHub Pages. The deployment process is incredibly simple. I initialized a local Git repository in my project folder on my machine. I committed all my code and pushed it to a public repository on my GitHub account. In the repository settings, I navigated to the Pages section and set the source to deploy directly from the main branch. GitHub handles the rest, providing me with a fast, secure, and globally distributed live link that I can share on my resume, my LinkedIn profile, and with anyone who wants to see my work.
